# Kurage 陳情・名簿

議員事務所のための業務システムです。支持者・後援会員の名簿、訪問の計画と記録、陳情・相談の進み具合、行事の案内と出欠を1つにまとめます。
PHP 8 と SQLite だけで動き、事務所のサーバーやレンタルサーバーに置けます。名簿を外のクラウドに預けません。

## できること

- **名簿** … CSV で取り込み（Excel の名簿。UTF-8／Shift_JIS、見出しで列を探す）。氏名と電話か住所が同じ人は重複として知らせる。同じ住所の家族、紹介した人・された人がつながる。宛名を世帯ごとに1通で書き出す。
- **訪問** … 地区・支持度・「3か月訪問していない」などで絞って地図に出し、事務所から近い順に回る順番を作る（直線の距離）。訪問先で、在宅・不在・話した内容・また伺う約束をスマホから記録する。紙にも印刷できる。
- **陳情・相談** … 受付から、行政への照会、回答、完了まで。段階ごとの板でカードを動かし、期限・担当・経過（いつ・だれが・何をしたか）を残す。
- **行事** … 名簿の条件で案内する人を選び、宛名を書き出し、出欠を付ける。
- **AI の下書き**（使う場合だけ）… 相談の記録から、要約と、相談した方へ送る文面の下書きを作る。事務所の中に置いた AI（Ollama など OpenAI 互換の口）につなぐ。
- 利用者ごとのログイン、管理者だけの書き出し、操作の記録、毎日の控え。

寄附・会費・収支の管理は入れていません。

## 置き方

1. `public/` の中身を、PHP 8.1 以上（pdo_sqlite・mbstring）が動く場所に置く。
2. `kcm_config.php.example` を `kcm_config.php` という名前で写し、事務所の名前を入れる。`kcm_data/` に PHP が書き込めるようにする（できれば `db` を公開フォルダの外にする）。
3. ブラウザで開き、最初の管理者を作る。
4. 「設定」で事務所の場所を地図で決める（訪問の順番の起点）。「名簿 → CSV で取り込む」で名簿を入れ、「位置を付ける」を押す。

外へ出る通信は3つで、どれも `kcm_config.php` で止められます。

- `map` … 地図の絵を OpenFreeMap から読む（名簿のデータは送りません）
- `geocode` … 住所から地図の位置を調べる（住所の文字だけを国土地理院の住所検索へ送ります。止めた場合は地図を押して位置を決めます）
- `ai_url` … AI の接続先（空なら AI のボタンは出ません）
